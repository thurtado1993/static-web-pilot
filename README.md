# Forn Molla d'Or — web de prueba

Web de un negocio **ficticio**, creada para pilotar el workflow `NEW_STATIC_WEB` de LifeBrain/Hermes. El negocio, la dirección y el teléfono no existen.

Publicada con GitHub Pages desde la rama `main`. Para previsualizarla en local, desde la raíz del repo:

```
python -m http.server 8000
```

y abrir `http://localhost:8000`.
